# POM POWER CRM — Android app (APK backup)

Backup of the Android app of POM POWER CRM.

- **Latest APK:** see [Releases](../../releases/latest). Every version built is kept there as `POM-POWER-CRM-<version>.apk`.
- **Code:** the `mobile/` folder is a copy of the app source (Expo / React Native) from the main CRM repository, taken at the version of the latest release.

The app is developed and built in the main repository (`pom-power-crm`, tag `apk-<version>`); this repository only keeps the copies.
